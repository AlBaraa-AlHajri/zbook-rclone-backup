Privacy Policy

ZBook Rclone Backup
Last updated: 12 November 2026

1. Scope

This policy describes the personal desktop backup application ZBook Rclone Backup, used by its owner with Rclone. The application is not offered as a service to the public.

2. Data accessed and purpose

The application requests the Google Drive drive.file scope. It may access the contents and metadata of files and folders created by or authorized for this application, including names, identifiers, sizes, timestamps, and checksums where available. Access is used only for owner-directed backup, listing, checking, and restoration of those files. The scope also permits editing and deletion of accessible files when the owner explicitly runs commands that perform those operations.

3. Storage and processing

Selected files are transferred between the owner's computer and Google Drive. Backup copies remain in the owner's Google Drive account. OAuth credentials and tokens are stored locally by Rclone according to the owner's configuration. Local logs may contain file paths, names, and operational errors if logging is enabled. This website does not collect backup content, credentials, or tokens.

4. Sharing and limited use

The application does not sell Google user data, use it for advertising, or use it to train generalized AI or machine-learning models. Data is sent to Google as necessary to provide the requested Drive storage and authorization. No separate application-operated server receives backup contents. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.

5. Retention and deletion

Files remain on the owner's computer and in Google Drive until the owner deletes them under the applicable storage and Trash retention settings. The owner controls retention of local logs and configuration files. Revoking OAuth access stops future authorized access but does not itself remove existing backup copies. The owner can remove copies through Google Drive and remove local credentials through Rclone configuration management when they are no longer needed.

6. Security and revocation

Google API communication uses HTTPS. The owner is responsible for securing the computer, credentials, tokens, and backup copies. This policy does not claim that local configuration files or uploaded file contents are additionally encrypted by this application. Access can be revoked in the Google Account's third-party connections settings.

7. This informational website

The pages contain no forms, advertising, analytics scripts, or application cookies. The hosting provider may process standard technical request data under its own privacy policy. Do not submit passwords, tokens, or backup files through this site.

8. Contact and changes

This is an owner-operated personal application. For application-related questions, use the support contact displayed by Google on the application's OAuth consent screen. The policy will be updated before introducing materially different data practices.
