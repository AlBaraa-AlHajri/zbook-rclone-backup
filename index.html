ZBook Rclone Backup

A personal OAuth application used with Rclone on Windows to copy selected local files to the owner's Google Drive account and support later restoration of accessible backup files.

Purpose and access

This application is intended for its owner's personal use. It is not a public backup service and does not offer accounts, subscriptions, or public sign-in through this website.

The application is configured to request https://www.googleapis.com/auth/drive.file. This permits access to files created by or explicitly authorized for this application. It does not grant unrestricted access to every file in Google Drive.

How it works

Rclone runs on the owner's computer. Google handles account sign-in and consent. Selected files are transferred between that computer and Google Drive; this informational website does not receive backup files or OAuth credentials.

Privacy and control

Read the Privacy Policy for details about data access, storage, retention, and revoking access. The owner controls backup commands, local credentials, and retained copies.

This is an independent personal configuration, not an official Google service or a service operated by the Rclone project.
